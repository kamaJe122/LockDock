# LockDock 鎖屏小工具盒 (Google Pixel 10 Pro XL · Android 17)

仿照 iPhone 鎖定畫面（iOS Lock Screen Widgets）打造的模組化毛玻璃鎖定畫面小工具 App，專為 **Google Pixel 10 Pro XL（Android 17 / API 37）** 設計與最佳化。

## 核心特色

1. **仿 iPhone 4 格自由組合鎖屏小工具列 (`IosShelfWidgetProvider`)**
   - 支援 **時鐘上方膠囊小工具**（日期＋電量／倒數日／自訂座右銘）。
   - 支援 **4 格自由混搭** `1×1` 圓環小工具與 `2×1` 長條膠囊小工具：
     - 🔋 **電量圓環 (`1×1`)**：即時電量百分比與充電閃電標記
     - 💧 **喝水打卡環 (`1×1`)**：在鎖定畫面**免解鎖直接點擊 `+1` 杯**，每日自動歸零
     - 🔦 **手電筒開關 (`1×1`)**：免解鎖直接在鎖定畫面開關 Pixel 閃光燈（無須相機權限）
     - 🔥 **習慣計數環 (`1×1`)**：自訂 Emoji 圖示與每日目標，鎖屏直接點擊 `+1`
     - ⏳ **年度進度環 (`1×1`)**：以 iOS 圓環顯示今年已過百分比
     - 🚀 **自選 App 捷徑 (`1×1`)**：任選喜愛 App，點擊觸發刷臉／指紋解鎖秒開
     - 📅 **倒數日膠囊 (`2×1`)**：重要紀念日、旅遊或目標倒數天數
     - ✅ **待辦事項膠囊 (`2×1`)**：顯示未完成待辦，點擊免解鎖開啟快速面板
     - 📝 **鎖屏備忘錄 (`2×1`)**：置頂座右銘或提醒，點擊免解鎖即時修改 (`showWhenLocked="true"`)

2. **互動式鎖屏待辦與備忘大卡片 (`TodoMemoWidgetProvider`)**
   - 支援在鎖定畫面直接點擊項目打勾完成，或點擊右上角免解鎖新增筆記。

3. **雙重鎖定畫面顯示模式**
   - **模式一（推薦・Android 17 原生鎖定畫面小工具）**：免特殊權限、極致省電，加入至 Pixel「鎖定畫面上的小工具」頁面。
   - **模式二（進階・主鎖定畫面時鐘正下方直接顯示）**：喚醒鎖屏即顯示於第一頁時鐘正下方（解鎖瞬間自動隱藏），並支援透過 `AppWidgetHost` 嵌入手機內**任何第三方 App 的小工具**（如天氣、Google 日曆、Spotify 等）。

## 編譯指令

```bash
ANDROID_HOME=/opt/android-sdk gradle assembleRelease
```
